## 🔬 Projetos

### Projeto I — Hábitos Alimentares na Pandemia
Análise de associações entre variáveis sociodemográficas e mudanças nos hábitos alimentares de 2310 indivíduos durante a pandemia de COVID-19 (2022). 

> Variável resposta: **consumo de doces**.

### Projeto II — Mortalidade por Câncer no Brasil
Dashboard exploratório interativo com dados de mortalidade por câncer do SIM/DATASUS (2001–2024). 

> Tipo de câncer analisado: **Câncer de Estômago (CID-10: C16)**.
